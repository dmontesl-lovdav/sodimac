Listo Fer, ya encontre el problema. Estas consultando el catalogo equivocado.

Los estatus de factura (EFA001-EFA014) estan en `CatEstatusFactura`, no en `CatEstatusComplemento`.

En la base de datos:
- CatEstatusFactura (id=15, prefix=EFA, status=1) → tiene los 14 estatus EFA con internalStatus poblado
- CatEstatusComplemento (id=19, prefix=ECM, status=-1) → vacio, aun no esta configurado

Cambia tu consulta de:
  GET /CatEstatusComplemento/details?lang=1  (regresa [])
a:
  GET /CatEstatusFactura/details?lang=1  (regresa los 14 estatus)

La API te va a devolver algo asi:
{
  "key": "EFA002",
  "internalStatus": 2,
  "description": "Pendiente Addenda",
  "color": "Amarillo",
  "sortOrder": 2
}

El campo `internalStatus` es el que debes mandar en el campo `status` del endpoint `POST /invoices/search`. El mapeo es:

EFA001 = 1 (Rechazo Comercial)
EFA002 = 2 (Pendiente Addenda)
EFA003 = 3 (Recibido Parcial)
EFA004 = 4 (Pendiente de Contabilizar)
EFA005 = 5 (En proceso de descarga)
EFA006 = 6 (Desglose de factura)
EFA007 = 7 (Pendiente de envio a contabilizar)
EFA008 = 8 (Pendiente de Pago)
EFA009 = 9 (Pagado)
EFA010 = 10 (Pendiente de complemento)
EFA011 = 11 (Completado)
EFA012 = 12 (Rechazo Contable)
EFA013 = 13 (No valido fiscal)
EFA014 = 14 (Pago Manual)

Ejemplo de uso:
POST /invoices/search
{
  "rfcEmisor": "",
  "fechaInicioRecepcion": "2025-08-07",
  "fechaFinalRecepcion": "2025-12-26",
  "tipoDocumento": "i",
  "page": 0,
  "size": 10,
  "status": 2
}
