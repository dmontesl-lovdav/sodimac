========================================================================
STM-1463 - Pruebas cURL para CMD de Windows (copia y pega)
util-api directo en puerto 3712
========================================================================

IMPORTANTE: cada curl esta en UNA SOLA LINEA. Copia la linea completa.
CMD de Windows no soporta saltos de linea con backslash (eso es Bash).


# 1. Health check (GET)
curl -s http://localhost:3712/health


# 2. Generar UUID (GET)
curl -s http://localhost:3712/api/activity-logs/uuid


# 3. Crear log de actividad (POST)
curl -sS -X POST http://localhost:3712/api/activity-logs/ -H "Content-Type: application/json" -d "{\"traceId\":\"11111111-1111-1111-1111-111111111111\",\"traceFrontId\":\"22222222-2222-2222-2222-222222222222\",\"modulo\":\"fiscal\",\"action\":\"CREATE_INVOICE\",\"serviceName\":\"fiscal-api\",\"userId\":\"PROV001\",\"isError\":false,\"message\":\"Factura creada exitosamente\",\"messageDetail\":\"UUID generado para la factura\",\"details\":{\"numeroFactura\":\"A-12345\",\"monto\":1500.75},\"durationms\":150,\"timestamp\":\"2026-04-15T10:30:00Z\"}"


# 4. Listar logs con filtros (GET con body JSON)
curl -sS -X GET http://localhost:3712/api/activity-logs/ -H "Content-Type: application/json" -d "{\"dateAtInitial\":\"2026-04-01T00:00:00Z\",\"dateAtEnd\":\"2026-04-15T23:59:59Z\",\"pageNumber\":1,\"pageSize\":20}"


# 5. Listar logs filtrando por modulo y servicio
curl -sS -X GET http://localhost:3712/api/activity-logs/ -H "Content-Type: application/json" -d "{\"dateAtInitial\":\"2026-04-01T00:00:00Z\",\"dateAtEnd\":\"2026-04-15T23:59:59Z\",\"modulo\":\"fiscal\",\"serviceName\":\"fiscal-api\",\"pageNumber\":1,\"pageSize\":10}"


# 6. Validar en BD (docker)
docker exec sodimac-pg psql -U wwwb2bportal -d b2b_portal -c "SELECT service_name, modulo, action, message, timestamp FROM core_audit.activity_logs ORDER BY timestamp DESC LIMIT 5;"


========================================================================
TIPS CMD Windows
========================================================================

- Si curl no responde o da "could not resolve host": verifica que
  util-api este corriendo (npm run dev en otra ventana) y que el puerto
  sea 3712.

- Si ves comillas raras al pegar: el editor a veces convierte " en
  comillas tipograficas. Pega directamente en CMD, no pases por Word.

- Alternativa si prefieres sintaxis limpia (como el curls.txt original):
  abre Git Bash (ya esta instalado en Sodimac). Ahi SI funcionan los
  curls multi-linea con single-quotes del archivo original.

- En PowerShell el comando "curl" es alias de Invoke-WebRequest
  (otro comando distinto). Para usar el curl real en PowerShell:
     curl.exe -s http://localhost:3712/health
  o simplemente usa CMD.

- Para el paso 6 (docker): si no tienes sodimac-pg corriendo en Sodimac,
  omite ese paso. Solo aplica si levantaste una copia local del
  PostgreSQL para pruebas. En tu caso en Sodimac probablemente te
  conectas a otra BD (la real dev o la de tu equipo).
