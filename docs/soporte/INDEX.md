## Como usar este registro

Cuando alguien del equipo reporta un problema o hace una consulta:

1. Abrir el archivo de la persona
2. Agregar una entrada nueva al inicio (mas reciente primero)
3. Incluir: fecha, contexto, problema, solucion y jira relacionado (si aplica)

Para buscar en todo el historial de soporte:
