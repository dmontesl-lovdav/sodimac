========================================================================
STM-1463 - Migrar el modulo de auditoria a utilerias BackEnd
Pruebas con cURL (util-api directo en puerto 3712)
========================================================================

# ------------------------------------------------------------------------
# 1. Health check de util-api (verifica que la API y la BD responden)
# ------------------------------------------------------------------------
curl -s http://localhost:3712/health


# ------------------------------------------------------------------------
# 2. Generar UUID (endpoint utilitario de auditoria)
# ------------------------------------------------------------------------
curl -s http://localhost:3712/api/activity-logs/uuid


# ------------------------------------------------------------------------
# 3. Crear log de actividad (POST)
#    Responde 201 inmediato; el INSERT corre en background.
# ------------------------------------------------------------------------
curl -sS -X POST http://localhost:3712/api/activity-logs/ \
  -H "Content-Type: application/json" \
  -d '{
    "traceId": "11111111-1111-1111-1111-111111111111",
    "traceFrontId": "22222222-2222-2222-2222-222222222222",
    "modulo": "fiscal",
    "action": "CREATE_INVOICE",
    "serviceName": "fiscal-api",
    "userId": "PROV001",
    "isError": false,
    "message": "Factura creada exitosamente",
    "messageDetail": "UUID generado para la factura",
    "details": {"numeroFactura":"A-12345","monto":1500.75},
    "durationms": 150,
    "timestamp": "2026-04-15T10:30:00Z"
  }'


# ------------------------------------------------------------------------
# 4. Listar logs con filtros (rango de fechas <= 30 dias)
# ------------------------------------------------------------------------
curl -sS -X GET http://localhost:3712/api/activity-logs/ \
  -H "Content-Type: application/json" \
  -d '{
    "dateAtInitial": "2026-04-01T00:00:00Z",
    "dateAtEnd": "2026-04-15T23:59:59Z",
    "pageNumber": 1,
    "pageSize": 20
  }'


# ------------------------------------------------------------------------
# 5. Listar logs filtrando por modulo y servicio
# ------------------------------------------------------------------------
curl -sS -X GET http://localhost:3712/api/activity-logs/ \
  -H "Content-Type: application/json" \
  -d '{
    "dateAtInitial": "2026-04-01T00:00:00Z",
    "dateAtEnd": "2026-04-15T23:59:59Z",
    "modulo": "fiscal",
    "serviceName": "fiscal-api",
    "pageNumber": 1,
    "pageSize": 10
  }'


# ------------------------------------------------------------------------
# 6. Validar en BD que el registro quedo insertado
# ------------------------------------------------------------------------
docker exec sodimac-pg psql -U wwwb2bportal -d b2b_portal \
  -c "SELECT service_name, modulo, action, message, timestamp \
      FROM core_audit.activity_logs \
      ORDER BY timestamp DESC LIMIT 5;"


========================================================================
Mensaje de commit sugerido
========================================================================

feat(util-api): migrar modulo de auditoria desde auditoria-api (STM-1463)

Se fusiona el codigo BackEnd del modulo de auditoria dentro de util-api
para evitar el desfase del pipeline de DevOps corporativo.

- Entity ActivityLogs registrada con schema: 'core_audit', la tabla no
  se mueve. util-api mantiene su schema principal core_utils.
- Endpoints migrados bajo el prefijo /api/activity-logs:
    GET  /uuid
    GET  /        (listado paginado con filtros)
    POST /        (crear log en background)
- Middleware de trazabilidad (AsyncLocalStorage) portado desde
  auditoria-api agregando soporte de trace_front_id via header.
- Logger unificado a pino (se descarta winston).
- UUID nativo con crypto.randomUUID (se descarta paquete uuid).
- Datasource registra ActivityLogs junto a las 7 entidades existentes.
- .env.example extendido con bloque de variables de auditoria.

Consumidores:
- fiscal-api: requiere apuntar AUDITORIA_API_URL a util-api (dev 3712).
- finanzas-api: escribe directo a BD, no requiere cambio.

Referencias: Epic STM-1403.
